# OG images moved

OG images are generated by the website's `/api/og` resource route on Cloudflare Workers. This directory retains only the Vercel deployment opt-out so the retired project stops building automatically. The separate Next.js app and its dependencies have been removed from the workspace.

After the website change is deployed, the old `og.simeongriggs.dev` hostname can be retired. Existing links to the old host require a host-level redirect if they need to remain supported.
